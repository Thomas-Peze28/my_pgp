# CLI Reference

[<- Back to README](../README.md)

## Syntax

```bash
./my_pgp CRYPTO_SYSTEM MODE [OPTIONS] [key]
```

The executable is generated by `make`. Every encryption or decryption command reads its message from standard input.

## Crypto systems

| System | Purpose | Current status |
| --- | --- | --- |
| `xor` | XOR symmetric encryption | Implemented |
| `aes` | AES symmetric encryption | Reserved, not implemented |
| `rsa` | RSA encryption and key generation | Reserved, not implemented |
| `pgp-xor` | RSA-wrapped session key with XOR payload encryption | Reserved, not implemented |
| `pgp-aes` | RSA-wrapped session key with AES payload encryption | Reserved, not implemented |

## Modes and options

| Option | Meaning |
| --- | --- |
| `-c` | Encrypt clear input. |
| `-d` | Decrypt ciphered input. |
| `-b` | Process one block. The message and symmetric key must have the same length. |
| `-g P Q` | Generate RSA keys from `P` and `Q`; valid only with `rsa`. |
| `-h`, `--help` | Print the usage text and exit successfully. |

`-c` and `-d` are mutually exclusive. A key is required for encryption and decryption. The key is supplied as a hexadecimal string for the current XOR implementation.

## Data formats

Stream encryption reads all binary input and returns hexadecimal text. If the final input block is shorter than the key, XOR stream mode pads it with zero bytes. Decryption returns the resulting bytes directly, so terminal output may contain non-printable bytes.

Block mode reads one line, removes its final newline, and requires the input length to match the key length. Decryption expects one hexadecimal ciphertext block.

## Examples

```bash
# Build once
make

# Encrypt a stream with a four-byte hexadecimal key
printf '12345678' | ./my_pgp xor -c 57686174

# Encrypt exactly one block
printf 'What\n' | ./my_pgp xor -c -b 57686174

# Decrypt hexadecimal ciphertext
printf '65535e455a4d4c4c' | ./my_pgp xor -d 57686174

# Display help
./my_pgp --help
```

RSA key generation uses the following syntax. The operation is parsed by the CLI but the RSA handler is not implemented yet:

```bash
./my_pgp rsa -g P Q
```

## Errors

The process exits with `0` after a successful operation. It writes an error message to standard error and exits with `84` for malformed arguments, invalid input, unsupported implementations, or any other exception.
